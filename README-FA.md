# بسته کامل وب‌سایت PIPEOX

این بسته شامل نسخه استاتیک و واکنش‌گرای وب‌سایت PIPEOX است.

## اجرا
1. فایل ZIP را از حالت فشرده خارج کنید.
2. فایل `index.html` را با مرورگر باز کنید.
3. برای انتشار، کل پوشه را بدون تغییر ساختار روی هاست یا فضای میزبانی استاتیک آپلود کنید.

## ساختار
- `index.html` صفحه اصلی فارسی و راست‌چین
- `assets/css/style.css` استایل‌ها و طراحی واکنش‌گرا
- `assets/js/main.js` منوی موبایل، جست‌وجوی محصولات و رفتار فرم
- `assets/js/config.js` تنظیمات اطلاعات تماس
- `assets/*.{jpg,png}` تصاویر استفاده‌شده در صفحه

## مواردی که پیش از انتشار باید تکمیل شوند
- در `assets/js/config.js` ایمیل، تلفن، واتساپ و نشانی واقعی شرکت را وارد کنید.
- متن‌ها و گروه‌های محصول را با کاتالوگ واقعی PIPEOX تطبیق دهید.
- تصاویر فعلی مفهومی/نمونه‌اند؛ تصاویر واقعی محصولات، کارخانه و پروژه‌ها را جایگزین کنید.
- فرم استعلام در نسخه فعلی، ایمیل را در نرم‌افزار ایمیل بازدیدکننده آماده می‌کند. برای دریافت مستقیم درخواست‌ها باید آن را به بک‌اند، CRM یا سرویس فرم متصل کنید.
- فونت Vazirmatn از Google Fonts بارگذاری می‌شود؛ در صورت نیاز به اجرای کاملاً آفلاین، فایل فونت را در پوشه assets قرار دهید و CSS را به‌روزرسانی کنید.

## نکته فنی
این نسخه فرانت‌اند استاتیک است و شامل پنل مدیریت، پایگاه داده، احراز هویت یا API سمت سرور نیست.


## جلوه‌های بصری و انیمیشن
- تصویر پس‌زمینه صنعتی در `assets/industrial-hero.webp` قرار دارد.
- بخش نمایش محصولات دارای حلقه‌های نورانی، شناوری آرام کارت‌ها و واکنش hover است.
- انیمیشن‌ها با تنظیم `prefers-reduced-motion` برای کاربرانی که حرکت کمتر می‌خواهند غیرفعال می‌شوند.
