# وب‌سایت PIPEOX

سایت چندصفحه‌ای فارسی (راست‌چین) برای تأمین لوله، اتصالات، فلنج و شیرآلات صنعتی.
- **طراحی (قالب):** Eleventy — لایه‌ها، CSS، آیکن‌ها. خروجی build فایل‌های **PHP** است.
- **محتوا و بک‌اند:** PHP 8 + SQLite — محصولات، مقالات، پروژه‌ها، تنظیمات، استعلام‌ها، حساب مشتری‌ها.

محتوا از پنل مدیریت ویرایش می‌شود و **بلافاصله** روی سایت می‌آید؛ برای تغییر محتوا نیازی به build دوباره نیست.
فقط تغییر طراحی (قالب‌ها، CSS، JS) نیاز به `npm run build` و آپلود دوباره دارد.

## اجرا

```bash
npm install       # فقط بار اول
npm run build     # ساخت نسخه نهایی در dist/
npm run serve     # سایت کامل روی http://localhost:8090 (نیاز به PHP 8 با pdo_sqlite)
```

## انتشار روی هاست (cPanel / DirectAdmin)

1. فایل `src/api/config.sample.php` را به `src/api/config.php` کپی و پر کنید: رمز پنل مدیریت، ایمیل یا ربات بله.
   ساخت هش رمز: `php -r "echo password_hash('رمز-شما', PASSWORD_DEFAULT);"`
2. `npm run build` را اجرا کنید و **محتوای `dist/`** را در `public_html` آپلود کنید (`mod_rewrite` باید فعال باشد؛ در هاست‌های معمول فعال است).
3. پوشه داده (`data_dir` در config) خودکار ساخته می‌شود و پیش‌فرض آن **بیرون از public_html** است:
   پایگاه داده، فایل‌های پیوست استعلام و تصاویر آپلودی پنل همه آن‌جا هستند. **از این پوشه نسخه پشتیبان بگیرید.**
4. اولین بار که سایت باز شود، محتوای اولیه (پوشه `seed/`) در پایگاه داده ریخته می‌شود. از آن به بعد پایگاه داده مرجع است.
5. در پنل ← تنظیمات سایت: دامنه و اطلاعات تماس را وارد کنید.

## پنل مدیریت — `/api/admin.php`

| بخش | کار |
|---|---|
| استعلام‌ها | صندوق درخواست‌ها، تغییر وضعیت، یادداشت داخلی، دانلود پیوست، خروجی Excel |
| محصولات | افزودن/ویرایش/حذف، تصویر، انواع، جدول مشخصات، کاربردها، جایگاه در تصویر صفحه اصلی |
| مقالات و اخبار | ویرایشگر متن با تیتر، فهرست، پیوند و تصویر · پیش‌نویس · انتشار زمان‌بندی‌شده |
| پروژه‌ها | پروژه‌های شاخص صفحه پروژه‌ها |
| مشتریان | حساب‌های ثبت‌نامی، فعال/غیرفعال، تعیین رمز جدید، خروجی Excel |
| خبرنامه | مشترکان، حذف، خروجی Excel |
| تنظیمات سایت | نام، دامنه، تماس، همه متن‌ها و آمار صفحه اصلی |

## حساب مشتری — `/account/`

ثبت‌نام و ورود با ایمیل و رمز. مشتری واردشده:
- استعلام‌هایش خودکار به حسابش وصل می‌شود و وضعیت هر کدام را می‌بیند (یادداشت‌های داخلی را نمی‌بیند)
- نام و تلفنش در فرم‌ها از قبل پر است
- اطلاعات و رمزش را تغییر می‌دهد

بازیابی رمز با ایمیل است و فقط وقتی کار می‌کند که ارسال ایمیل در `config.php` فعال باشد؛
در غیر این صورت مدیر از بخش «مشتریان» برای مشتری رمز جدید تعیین می‌کند.

## ساختار

```
seed/                    ← محصول، مقاله و متن‌های اولیه (فقط برای نصب اول)
scripts/
├─ export-seed.mjs       ← seed/ → src/api/seed/seed.json (در هر build)
├─ dev-router.php        ← قوانین .htaccess برای سرور محلی PHP
└─ extract-mockup-assets.mjs ← برش تصاویر صفحه اصلی از طرح
src/
├─ _data/site.json       ← منوی سایت
├─ _includes/
│  ├─ layouts/           ← base (head و سئو) · page (صفحات داخلی)
│  ├─ partials/          ← header · footer · quote-form · quote-modal · product-card · story-card · cta
│  └─ styles/            ← CSS به تفکیک بخش (در build یک فایل می‌شود)
├─ index.njk · about · contact · projects · 404
├─ products/             ← index (فهرست) + item (صفحه هر محصول: /products/<نامک>/)
├─ insights/             ← index (فهرست) + item (صفحه هر مقاله: /insights/<نامک>/)
├─ account/              ← ورود، ثبت‌نام، بازیابی رمز، داشبورد مشتری
├─ api/
│  ├─ inquiry.php · subscribe.php · media.php · admin.php   ← تنها فایل‌های قابل دسترس از وب
│  ├─ pages/             ← کنترلر صفحات پویا (محصول، مقاله، حساب‌ها)
│  ├─ lib/               ← bootstrap (DB) · site (محتوا، تاریخ شمسی) · auth · notify · smtp · admin/
│  └─ config.sample.php  ← نمونه تنظیمات (config.php در git نیست)
└─ assets/  img/ · fonts/ · js/main.js
```

## نکات
- تلگرام از اغلب سرورهای داخل ایران در دسترس نیست؛ برای هاست ایرانی از **بله** استفاده کنید.
- نقشه سایت، تگ canonical و تصویر اشتراک‌گذاری فقط وقتی دامنه در تنظیمات وارد شده باشد کامل می‌شوند.
- متن مقالات هنگام ذخیره پاک‌سازی می‌شود (اسکریپت، استایل و ویژگی‌های خطرناک حذف می‌شوند).
- تصاویر آپلودی تا ۵ مگابایت‌اند؛ اگر افزونه GD روی هاست باشد، عکس‌های بزرگ‌تر از ۲۰۰۰ پیکسل خودکار کوچک می‌شوند.
