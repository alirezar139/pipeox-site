# وب‌سایت PIPEOX

سایت استاتیک فارسی (راست‌چین) که با [Eleventy](https://www.11ty.dev/) ساخته می‌شود.

## اجرا
```bash
npm install      # فقط بار اول
npm start        # سرور توسعه با بارگذاری خودکار: http://localhost:8080
npm run build    # ساخت نسخه نهایی در پوشه dist/
```
برای انتشار، **محتوای پوشه `dist/`** را روی هاست آپلود کنید. خود `src/` و `node_modules/` آپلود نمی‌شوند.

## ساختار
```
src/
├─ _data/
│  ├─ site.json        ← نام، توضیحات سئو، اطلاعات تماس، منو
│  └─ products.json    ← گروه‌های محصول (کارت‌ها، نمایش مداری، فرم و فوتر از اینجا ساخته می‌شوند)
├─ _includes/
│  ├─ layouts/base.njk ← اسکلت HTML همه صفحات
│  ├─ partials/        ← header، footer، فرم استعلام
│  └─ styles/          ← CSS به تفکیک بخش (در build به یک فایل style.css تبدیل می‌شود)
├─ assets/  img/ · fonts/ (Vazirmatn محلی) · js/main.js
├─ index.njk           ← صفحه اصلی
└─ .htaccess           ← کش، فشرده‌سازی و هدرهای امنیتی Apache
```

## کارهای رایج
- **اطلاعات تماس:** در `src/_data/site.json` بخش `contact` را پر کنید. فوتر و فرم خودکار به‌روز می‌شوند.
- **افزودن یا ویرایش محصول:** در `src/_data/products.json`.
- **تغییر ظاهر:** فایل مربوط را در `src/_includes/styles/` ویرایش کنید.

## وضعیت فرم استعلام
تا وقتی endpoint سمت سرور (فاز ۲) آماده نشده، فرم یک پیش‌نویس ایمیل به آدرس `contact.email` باز می‌کند. اگر ایمیل تنظیم نشده باشد، به کاربر پیام می‌دهد و در صورت وجود، شماره تماس را نشان می‌دهد.

## پیش از انتشار
- اطلاعات واقعی تماس را در `site.json` وارد کنید.
- تصاویر نمونه را با تصاویر واقعی محصولات و پروژه‌ها جایگزین کنید.
